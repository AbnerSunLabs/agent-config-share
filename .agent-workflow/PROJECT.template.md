## 6. Review Profile

基础 Review 永远启用：correctness、acceptance、testing、error-handling、compatibility、security、maintainability。

按项目选择额外 Profile：

- [ ] `web`：可访问性、浏览器行为、响应式和视觉回归。
- [ ] `api`：协议、错误码、幂等、限流和向后兼容。
- [ ] `database`：迁移、锁、事务、索引、回滚和数据完整性。
- [ ] `security`：认证、授权、输入、凭证和敏感数据。
- [ ] `agent`：上下文、工具权限、Prompt 注入、终止条件和成本。
- [ ] `infrastructure`：权限、资源生命周期、回滚和生产影响。
- [ ] `mobile`：设备、系统版本、离线、权限和性能。

## 11. 降级策略

- 无独立 Reviewer Agent：使用新会话；仍不可用时按 Review 模板串行复审。
- 无项目级 touched-scope 命令：运行最窄可用检查，并在交付前运行完整命令。
- 无法运行某项验证：记录具体阻断和影响，不得将其写成通过。
- 无 Git 仓库：L2 自动降级为 L1，并在最终交付中说明。
