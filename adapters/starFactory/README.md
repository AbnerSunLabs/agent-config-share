# starFactory 适配

**源只在本目录。** 用 starFactory 开发某个仓库时，按 starFactory 目录约定做路径对齐。

| 本仓库源                         | 开发仓库对齐到           |
| -------------------------------- | ------------------------ |
| `adapters/starFactory/AGENTS.md` | `.starFactory/AGENTS.md` |

须同时具备 `.agent-workflow/`。

- `AGENTS.md`：工作流入口（对齐到开发仓库）
- `README.md`：本说明（不对齐）

边界：生命周期与门禁见 `.agent-workflow/WORKFLOW.md`；能力对照见 `CAPABILITIES.md`。
